# Execution Plans

Working directory for multi-step agent execution plans (design docs, migration plans, task breakdowns) that are too large for a PR description.

- Put in-progress plans in `active/`, move finished ones to `completed/` (create the directories as needed).
- Plans are working documents, not authoritative documentation — the source of truth stays in [`../ARCHITECTURE.md`](../ARCHITECTURE.md), `AGENTS.md`, and the code.
- Delete or archive plans that no longer match the repo state instead of letting them drift.
